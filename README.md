# Borsa Defteri

Kişisel ABD borsası takibi için küçük bir PWA: portföy, kendi puanlama yöntemimiz, senaryolu hedef, reverse DCF, bilanço takvimi ve insider özeti. Veriler Finnhub'dan gelir.

- Portföy ve Finnhub anahtarı **yalnızca kullanıcının cihazında** (tarayıcı depolaması) saklanır; bu depoda kişisel veri yoktur.
- Puanlar, hedefler ve takvim kendi yöntemimizdir; eğitim ve kişisel takip amaçlıdır, **yatırım tavsiyesi değildir**.

Yerelde çalıştırma: `node serve.js` → http://localhost:5173
